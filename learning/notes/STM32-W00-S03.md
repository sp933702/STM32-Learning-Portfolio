## 問題與筆記

### [筆記] 2026-07-24 00:00

已完成 STM32F103C8T6 相關文件整理，包含 DS5319 Datasheet、RM0008 Reference Manual、PM0056 Programming Manual、ES096 Errata、AN2586 Hardware Guide，以及 Blue Pill USB-C 板正反面與板卡資料。

已理解各文件用途：
1. Datasheet：查晶片規格、腳位、封裝、電氣限制。
2. Reference Manual：查 GPIO、UART、ADC、I²C 等周邊暫存器與操作方式。
3. Programming Manual：查 Cortex-M3、NVIC、SysTick、HardFault、堆疊與 CPU 暫存器。
4. Schematic：查開發板 LED、按鍵、晶振、USB、SWD 等實際接線。
5. Errata：查晶片已知缺陷與官方 workaround。

查找練習結果：
- STM32F103C8T6 屬於 STM32F103x8 系列。
- C 代表 48 pins，T 代表 LQFP，因此為 LQFP48。
- SWDIO = PA13 / Pin 34。
- SWCLK = PA14 / Pin 37。
- Flash 起始位址為 0x08000000。
- STM32F103C8T6 的 64 KB Flash 結束位址為 0x0800FFFF。
- PC13 在 LQFP48 封裝中為 Pin 2。

曾混淆的部分：
- 暫存器 bit 定義應查 Reference Manual，不是 Datasheet。
- 板載 LED 接到哪一支 GPIO 應查板子 Schematic，不是 MCU Datasheet。
