## 問題與筆記

### [筆記] 2026-08-04 00:00

PA1 類比電壓
→ ADC1_IN1
→ ADC Raw（0～4095）
→ 換算為毫伏
→ 顯示成 0.000～3.300 V
→ USART1 輸出

本節使用：
PA1 → ADC1_IN1
各部分意義：
PA1   → MCU 的 GPIO 腳位
ADC1  → 第 1 組 ADC 周邊
IN1   → ADC1 的輸入通道 1
IN1 是 Input Channel 1，不是 1 V

Sampling Time
原本設定：

1.5 Cycles
後來改為：
55.5 Cycles
原因是 ADC 內部有取樣電容，需要時間讓它充電至輸入電壓。
較長的 Sampling Time：
優點：對較高阻抗訊號較穩定
缺點：單次轉換時間稍長

STM32F103 的 ADC 為 12-bit：
2¹² = 4096 種輸出值
輸出的數字範圍：
0～4095
理想對應關係：
ADC Raw = 0       → 0 V
ADC Raw ≈ 2048    → 約 1.650 V
ADC Raw = 4095    → 約 3.300 V

因為：
Continuous Conversion Mode = Disabled
所以每次量測都需要重新啟動 ADC。
基本流程：
1. HAL_ADC_Start()
2. HAL_ADC_PollForConversion()
3. HAL_ADC_GetValue()
4. HAL_ADC_Stop()

PA1 / ADC1_IN1 單次取樣
→ ADC 校正
→ HAL_ADC_Start()
→ 等待轉換完成
→ 讀取 12-bit Raw 值
→ 換算成 mV
→ 四捨五入
→ 顯示為 0.000～3.300 V
→ Start／Poll 失敗檢查
→ 資料有效旗標
→ ADC Stop
→ UART 錯誤訊息

整數除法要做到四捨五入，可以在分子加上：
除數的一半
目前除數：
4095
整數的一半：
4095 / 2 = 2047

不使用浮點數顯示電壓
系統內部儲存：
adc_voltage_mv = 1650
要顯示為：
1.650 V
可使用整數除法和餘數。
整數部分：
adc_voltage_mv / 1000U
小數部分：
adc_voltage_mv % 1000U
例如：
1650 / 1000 = 1
1650 % 1000 = 650
→ 1.650 V
