### [筆記] 2026-07-28 00:00

if (GPIO_Pin == INTERRUPT_BUTTON_Pin)，不是在判斷 PB0 目前是否為低電位，而是在確認這次 Callback 是否由 INTERRUPT_BUTTON_Pin，也就是 PB0 所對應的 EXTI0 中斷所觸發。
PB0 發生 High → Low
→ EXTI Line 0 偵測到下降沿
→ NVIC 接收到 EXTI0 中斷請求
→ CPU 進入 EXTI0_IRQHandler()
→ HAL_GPIO_EXTI_IRQHandler(INTERRUPT_BUTTON_Pin)
→ HAL_GPIO_EXTI_Callback(INTERRUPT_BUTTON_Pin)
EXTI 模式：決定什麼時候觸發
GPIO_Pin：指出是哪個 Pin 觸發
NVIC：管理中斷並通知 CPU
