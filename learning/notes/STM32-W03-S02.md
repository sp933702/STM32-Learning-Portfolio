## 問題與筆記

### [筆記] 2026-07-29 00:00

Pulse Width Modulation
脈衝寬度調變
Duty 0%   ：一直 Low，LED 不亮
Duty 25%  ：亮的時間較短，看起來較暗
Duty 50%  ：中等亮度
Duty 75%  ：亮的時間較長，看起來較亮
Duty 100% ：一直 High，LED 最亮

PSC：決定 Timer 計數速度
ARR：決定 PWM 的完整週期
CCR：決定 High 維持多久

TIM2_CH1 在 PA0 輸出 1 kHz PWM
透過 CCR1 改變 Duty Cycle
使用 HAL_GetTick()，沒有 HAL_Delay()
亮度能持續增加與降低
上限夾制為 1000
下限夾制為 0
避免 uint16_t 下溢
固定參數與執行狀態分開管理
