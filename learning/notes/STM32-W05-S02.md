### [筆記] 2026-07-31 00:00

uart_rx_byte
→ HAL UART 中斷接收的暫存位置
uart_rx_buffer
→ 保存尚未由 main() 處理的多筆資料
uart_rx_write_index
→ Callback 修改，main() 讀取
uart_rx_read_index
→ main() 修改，Callback 讀取
uart_rx_overflow_count
→ 記錄 Buffer 滿時丟棄了幾個 byte

加入：
_Static_assert(
    (UART_RX_BUFFER_SIZE != 0U) &&
    ((UART_RX_BUFFER_SIZE &
      (UART_RX_BUFFER_SIZE - 1U)) == 0U),
    "UART_RX_BUFFER_SIZE must be a power of two");
判斷 2 的冪次的條件：
(SIZE & (SIZE - 1U)) == 0U
_Static_assert(條件, "錯誤訊息");
它是 C11 的編譯期檢查：
條件成立 → 正常 Build
條件失敗 → 編譯錯誤

卡關一：保留空位是否固定在某個 index？
不是。
保留的是「一個動態空位」，其位置會隨讀寫索引移動。若固定某個 index 永遠不用，只是縮小了循環範圍，仍無法單靠讀寫索引分辨空與滿。
