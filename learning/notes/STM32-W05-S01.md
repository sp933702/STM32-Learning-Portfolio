## 問題與筆記

### [筆記] 2026-07-30 00:00

HAL_UART_Receive_IT()
不是「等待資料」，
而是「安排下一筆中斷接收工作」。

在：
USART1 → NVIC Settings
勾選：
USART1 global interrupt
產生程式後，中斷入口會呼叫：
void USART1_IRQHandler(void)
{
    HAL_UART_IRQHandler(&huart1);
}

在初始化完成後、進入 while (1) 前呼叫一次：
HAL_UART_Receive_IT(&huart1,
                    &uart_rx_byte,
                    1U);
這不是等待資料，而是設定：
使用 USART1
→ 接收 1 byte
→ 存入 uart_rx_byte
→ 收完後產生中斷
函式會立即返回，不會卡住 CPU。

Callback 只做兩件事：
設定事件旗標
重新啟動下一次 1-byte 接收

流程：
開機啟動接收
→ 收到第 1 byte
→ Callback
→ 重新啟動接收
→ 收到第 2 byte
→ Callback
→ 持續循環

限制
目前只有：
1 個 uart_rx_byte
1 個 uart_rx_event
若資料連續快速到達，下一個字元可能在主迴圈處理前覆蓋上一個字元。
