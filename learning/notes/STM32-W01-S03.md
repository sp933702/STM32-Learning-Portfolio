## 問題與筆記

### [筆記] 2026-07-26 00:00

已完成 STM32-W01-S03。
使用 STM32CubeMX 將 PC13 設為 GPIO Output，Initial Output Level 設為 High，User Label 設為 LED，並保留 PA13/PA14 作為 SWDIO/SWCLK。
CubeMX 產生 LED_Pin 與 LED_GPIO_Port 定義後，在 main.c 的 USER CODE BEGIN 3 區段加入 HAL_GPIO_TogglePin() 與 HAL_Delay(500)。
Build 結果為 0 errors、0 warnings。透過 ST-LINK 進入 Debug，按 F8 執行後，板載 LED 能以固定週期規律閃爍，確認 GPIO 設定、HAL 控制、燒錄與實機執行皆正常。目前無卡關。
