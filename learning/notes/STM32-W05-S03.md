## 問題與筆記

### [筆記] 2026-07-31 00:00

本節已完成從「UART 單一 Byte 接收」進展到「具備基本命令列介面的韌體系統」

本節完成的命令：
status
help
get led
set led on
set led off
同時支援：
無效命令
命令長度超過限制
輸入字元即時顯示
空命令按 Enter 換行

收到的字元不是 '\r' 或 '\n' 時：
確認 Command Buffer 還有空間。
將字元存入 Buffer。
命令長度加一。
將字元 Echo 回終端機。

每一行結束後必須清除：
uart_command_overflow = 0U;
uart_command_length = 0U;
否則發生一次 Overflow 後，後續正常命令也可能持續被判斷成過長。
